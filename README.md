# 🚀 LongOS - Web-based Operating System (2026/2027 Edition)

**LongOS** is an advanced, high-performance web-based operating system simulator built with pure HTML5, Tailwind CSS, and vanilla JavaScript. It blends the classic productivity of Windows 10 with the sleek, next-generation Fluent Design and Mica transparency effects of Windows 11.

---

## ✨ Key Features

* **Dual OS Boot Manager:** Choose between booting into **Windows 10 OS 26 (Stable)** or **Windows 11 OS 27 (Next-Gen Fluent)** complete with a custom BIOS screen, boot animation, and synthesized startup/shutdown sound effects powered by the Web Audio API.
* **Auto Device Mode Adaptation:** Automatically detects if the user is on a desktop or mobile device, seamlessly toggling between a draggable window-based **Desktop Mode** and a touch-optimized **Mobile Mode**.
* **Liquid Glass & Mica UI:** Modern translucent frosted-glass aesthetics achieved through advanced CSS `backdrop-filter`, blur effects, and dynamic shadow layers.
* **Fully Functional Window Management:** Open, close, minimize, maximize, snap, drag, and manage multiple app windows effortlessly via an interactive **Task View**.
* **Built-in Applications & Utilities:**
  * **Media Player:** Supports local audio/video file imports, sample tracks (Synthwave/Lofi Beats), an audio visualizer canvas, and equalizer controls.
  * **Hardware Diagnostics:** Interactive testing suite for keyboards (key-press lighting), mouse responsiveness, stereo audio channel balance (left/right speaker tests), and dead-pixel screen checks.
  * **Lucky Wheel:** An interactive customizable prize/decision-making wheel with smooth animation physics.
  * **Command Prompt (CMD):** Retro terminal environment for system command execution.
  * **Task Manager & System Info:** Monitor real-time JavaScript heap memory usage, thread counts, and system build properties.

## 📦 Getting Started & Deployment

To run LongOS locally or deploy it online via **GitHub Pages**:

1. Clone or download this repository.
2. Rename the main source file to `index.html`.
3. Push the file to your GitHub repository.
4. Go to your repository **Settings** -> **Pages** -> Set the source branch to `main` to get your public live link instantly!
