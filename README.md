# 🚀 LongOS - Web-based Operating System (Next-Gen OS 27 Edition)

**LongOS** is an advanced, high-performance web-based operating system simulator built with pure HTML5, Tailwind CSS, and vanilla JavaScript. It blends the classic productivity of Windows 10 with the sleek, next-generation Fluent Design, centered Windows 11 Taskbar, and glowing Mica transparency effects of Windows 11 OS 27.

---

## ✨ Key Features

* **Dual OS Boot Manager:** Choose between booting into **Windows 10 OS 26 (Classic Left)** or **Windows 11 OS 27 (Next-Gen Centered)** complete with a custom BIOS screen, boot animation, and synthesized startup/shutdown sound effects powered by the Web Audio API.
* **Centered Windows 11 Taskbar & Dynamic Orbs:** Featuring a true Windows 11 centered taskbar layout combined with ambient glowing background orbs for an immersive desktop experience.
* **Persistent Custom Wallpaper (LocalStorage):** Easily upload and customize your own desktop wallpaper via the built-in Settings app. Images are stored securely in your browser's `localStorage` so they persist across reloads and sessions.
* **Auto Device Mode Adaptation:** Automatically detects if the user is on a desktop or mobile device, seamlessly toggling between a draggable window-based **Desktop Mode** and a touch-optimized **Mobile Mode**.
* **Fully Functional Window Management:** Open, close, minimize, maximize, snap, drag, and manage multiple app windows effortlessly via an interactive **Task View**.
* **Built-in Applications & Utilities:**
  * **Settings & Wallpaper:** Personalize your desktop background with instant local storage saving.
  * **Media Player:** Supports local MP4 video and MP3 audio file imports, progress scrubbing, volume control, and fullscreen playback.
  * **Hardware Diagnostics & System Info:** Comprehensive suite for monitoring system performance and app processes.
  * **Lucky Wheel:** An interactive customizable prize/decision-making wheel with smooth animation physics.
  * **Command Prompt (CMD):** Retro terminal environment supporting `help`, `cls`, `ver`, `date`, and `echo` commands.
  * **Task Manager:** Monitor real-time system applications and memory usage.
